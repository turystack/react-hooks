# @turystack/react-hooks

Platform-agnostic React utility hooks.

## Installation

```bash
pnpm add @turystack/react-hooks
```

### Peer dependencies

The host application provides these:

```bash
pnpm add react
```

## Entry points

```ts
import { /* … */ } from '@turystack/react-hooks'
import { /* … */ } from '@turystack/react-hooks/*'
```

## Documentation

Options, API reference and examples:

**https://tury.dev/libs/react-hooks**

## Development

```bash
pnpm install
pnpm typecheck
pnpm check
pnpm test
pnpm build
```
